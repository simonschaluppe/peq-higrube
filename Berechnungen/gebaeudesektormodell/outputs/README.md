# Ergebnisstände

Die Dateien direkt in diesem Ordner stammen aus der veröffentlichten vorläufigen Rechnung
vom 05.11.2026. Sie werden vom neuen Analyseweg nicht als Eingabe verwendet.

Neue Ergebnisse entstehen ausschließlich unter `analyse/`, sobald die vollständige
Flächenlieferung vorliegt. `analyse/bestand.parquet` ist die Übergabe ans Dashboard.
Bis dahin existiert kein neuer fachlicher Ergebnisstand. Technische Beispieldaten liegen
nur unter `.local/refactor-smoke` und dürfen nicht veröffentlicht werden.
